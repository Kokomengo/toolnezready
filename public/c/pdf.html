PDF

Put documents together and take them apart again.

Match the tool to the document

Images to PDF puts photos on pages; it does not merge existing PDFs. PDF to images renders pages as pictures. PDF to text reads an existing text layer, so a scan may return no text. Text to PDF makes a basic document from plain notes.

Before sending a document, open the exported file and check page order, small print and unusual characters. Keep digitally signed originals unchanged. PDF reading tools download a decoder library while processing the document locally.
