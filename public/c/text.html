Keep a source copy when cleaning text

Use word count to inspect a draft, case conversion to fix capitalization, clean text to remove selected formatting noise, and Markdown for structured notes. These operations can be combined, but removing accents or duplicate lines may change the meaning.

Compare the transformed result before replacing the source. The Markdown draft is stored in this browser; export it if it matters. Word counts and reading-time estimates may differ from the rules of a publishing platform.
