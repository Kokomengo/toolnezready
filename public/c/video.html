Video

Trim, compress and export clips straight from the browser.

Plan a short test export

Trim unwanted seconds before reducing bitrate. For fast action, preserve more bitrate than you would for a stationary speaker. A lower frame rate or width can save space, but check whether small text remains legible.

Video tools use browser decoding and recording. Exports take time and the available codecs differ between browsers. Test a short segment before committing to a long job, keep the tab open and inspect the downloaded file in the application that will receive it.
