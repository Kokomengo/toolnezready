Clean up text

Duplicates, stray spaces, accents and odd line breaks.

Remove selected kinds of formatting noise from copied text. Choose only the operations you need, because some options intentionally change meaningful characters or line structure.

How to use this tool

  1. Paste the copied text.
  2. Select operations such as trimming spaces or removing duplicate lines.
  3. Apply, compare the result with the original, and copy it.
The result will show up here.

Worked example

For a pasted list with accidental empty lines and repeated entries, trim spaces and remove duplicates. Leave accent removal off when names must keep their spelling.

Limitations and checks

Removing accents changes text; removing duplicates can delete intentional repetitions. This is not a spelling checker or an HTML parser. Preserve a copy of the source.
