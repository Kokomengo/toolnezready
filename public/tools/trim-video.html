Trim video

Keep the part that matters and drop the rest.

Export only the selected portion of a clip. ToolNez records a new video through the browser, so this is a re-encoded cut rather than a lossless copy of the source stream.

How to use this tool

  1. Open a playable video and preview it.
  2. Set start and end times for the section you want.
  3. Trim with the tab open, then play the saved file to check sound and endpoints.

Video is re-encoded by playing it through, so the job takes roughly as long as the selected clip. Keep the tab visible while it runs.

Worked example

To keep seconds 5 through 20, set start to 0:05 and end to 0:20. The resulting clip lasts about 15 seconds and takes roughly that long to encode.

Limitations and checks

Output codec support depends on the browser. Re-encoding can change quality and timing slightly. Long clips consume memory and time; use a desktop editor for exact lossless cuts.

Read the related workflow guide for choosing settings and verifying exports.

Why it takes as long as the clip

The browser plays the video onto a canvas and records the output with MediaRecorder, the same engine behind video calls. That forces real time, but it also means there is no queue and no waiting room.

For long trims keep the tab in the foreground: if the browser puts it to sleep, the recording pauses with it.

Common questions

Does it lose quality?

A little, because the clip is re-encoded. At 4 Mbps it holds up well to 1080p. If you need a lossless cut, that is a job for a desktop app.
