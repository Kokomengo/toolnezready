Images to PDF

Loose photos or scans turned into one document.

Package photos or scans into a document with one image on each page. The original files remain separate, and the new PDF contains raster pages rather than selectable text.

How to use this tool

  1. Add images and reorder them with the up/down controls.
  2. Choose A4, Letter or fit-to-photo, orientation and margins.
  3. Build the PDF and open it to check page order and readability.
Drop your imagesEach one becomes a page, and you can reorder them after

Worked example

For three receipt photos, select A4 and a modest margin, place the earliest receipt first, and check that small totals remain readable in the saved PDF.

Limitations and checks

This tool does not merge existing PDFs or perform OCR. Images are embedded as JPEG and may be downscaled. It is not suitable for preserving a digitally signed original document.

Read the related workflow guide for choosing settings and verifying exports.

What people actually use this for

The usual case: someone asks for your ID, a signed contract or three receipts "as a single PDF" and all you have is phone photos. Drop them in, put them in order, done. A4 portrait with a 20 point margin looks close enough to a proper scan.

The file is built by a small generator that embeds each photo as JPEG inside the PDF, so the result weighs about the same as the images together and opens in any reader.

Common questions

Can I put several photos on one page?

Not yet - each image takes a page of its own. If you need a grid, build the collage first and add it as a single image.
