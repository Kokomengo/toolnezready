Hash calculator

SHA-256 and friends, from a piece of text or a file.

Compute a SHA digest of text or file bytes. Hashes help compare an expected file checksum against a downloaded file without revealing or changing the content.

How to use this tool

  1. Choose text or a file and select the algorithm.
  2. Calculate the digest.
  3. Compare the entire output with a trusted checksum using the same algorithm.

Worked example

The SHA-256 digest of the exact text “abc” starts with ba7816bf and ends with f20015ad. Adding a newline changes the digest, even if the visible word looks the same.

Limitations and checks

A hash is not encryption and cannot restore the original file. A matching hash is useful only when the expected value comes from a trusted source. Plain SHA is not a suitable password-storage scheme.

Read the related workflow guide for choosing settings and verifying exports.

What a hash is for

To check that a file is exactly the one you expected. Plenty of downloads publish their SHA-256; if the one you get here matches, the file has not been corrupted or tampered with along the way.

SHA-1 still turns up in older systems, but it is broken for security purposes: use it only to verify legacy downloads, never to sign anything.
