JSON formatter

Tidy it, minify it, and find where the error is.

Validate JSON syntax and produce a readable or compact representation. This helps inspect data, but it does not validate an application-specific schema or whether the values are correct.

How to use this tool

  1. Paste JSON with double-quoted keys and strings.
  2. Choose formatting or minification.
  3. Read syntax errors and correct the input before copying the result.
Paste something and press Tidy up.

Worked example

The compact object {"name":"Ada","active":true} can be formatted with line breaks and indentation. A trailing comma after true is invalid JSON.

Limitations and checks

Comments and JavaScript expressions are not JSON. Parsing and re-serializing may change number representations; very large integer values can lose precision. Keep exact identifiers as strings.
