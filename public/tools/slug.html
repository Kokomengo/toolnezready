Slug generator

Turn a headline into a clean URL.

Turn a title into a readable URL segment by normalizing characters and separators. The output is a starting point for a route, not a check that the URL is available.

How to use this tool

  1. Paste the headline or label.
  2. Choose the separator and normalization options.
  3. Review the result before using it in a URL.
—

Worked example

“Summer Sale 2026” can become summer-sale-2026. Different titles can normalize to the same slug, so a publishing system may need a suffix to keep routes unique.

Limitations and checks

Removing accents or unsupported characters can change meaning. Slugs do not include a domain, and the tool does not check uniqueness or redirect existing links.
