Password generator

Solid passwords and an honest meter of how long they hold up.

Generate random passwords using browser cryptographic randomness. A strong generated password should be unique to one account and saved in a trusted password manager.

How to use this tool

  1. Choose length and allowed character sets.
  2. Generate a password that meets the destination requirements.
  3. Copy it into your password manager and enable multifactor authentication where available.

Worked example

A randomly generated 20-character password is a sensible starting point where long passwords are accepted. Generate a different one for each account; do not reuse a memorable example.

Limitations and checks

The strength meter assumes random character selection and a hypothetical guessing rate. It cannot predict a real breach or make a reused password safe. ToolNez does not store generated passwords.

Read the related workflow guide for choosing settings and verifying exports.

What the bar measures

Entropy in bits, which is the number of guesses somebody would need working at random. Every extra bit doubles the attacker's work. Below 50 bits a modern graphics card is done in hours; past 80 it becomes impractical with today's technology.

What matters most

  • Length beats exotic symbols: correct-horse-battery-staple holds up better than P@ssw0rd!.
  • A different password for every site. Reuse one and somebody else's breach takes all your accounts.
  • Two-factor authentication wherever it exists; it turns a leaked password into a scare instead of a disaster.

Passwords are produced with crypto.getRandomValues(), not Math.random().
