Generate favicons

Every size a site asks for, bundled in a ZIP.

Create PNG icon sizes and an HTML snippet for a website from one source image. Starting with a recognizable square mark makes the smallest exports easier to read.

How to use this tool

  1. Add a square source image with clear edges.
  2. Check the preview and generate the icon sizes.
  3. Download the ZIP, place the PNG files on your site, and adjust the supplied HTML paths.
Drop your logoSquare, with a little padding; PNG or rasterised SVG
You get 16, 32, 48, 180, 192 and 512 px, plus the HTML snippet to paste into your head.

Worked example

A simple letter or geometric mark on a 512 × 512 source usually survives a 16 × 16 export better than a detailed photograph. Inspect the smallest size before publishing.

Limitations and checks

The bundle contains PNG assets, not a multi-resolution ICO file. Non-square sources can be stretched. Browser and operating-system icon requirements may need additional manifest configuration.
