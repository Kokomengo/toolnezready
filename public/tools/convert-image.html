Convert images

PNG to JPG, to WebP, or the other way round. Many at once.

Choose a file format for the destination where your picture will be used. This converter decodes the original image and exports a new raster image; changing the filename alone would not convert it.

How to use this tool

  1. Add one or more readable images.
  2. Choose WebP for modern websites, JPEG for broad compatibility, or PNG for transparency.
  3. Set quality for JPEG or WebP, convert, and compare the preview and file size before saving.

Worked example

For a transparent shop logo, choose PNG or WebP. For a photograph attached to an email, choose JPEG. A larger output is possible when the original was already compressed.

Limitations and checks

Animation and original metadata are not preserved. JPEG cannot retain transparency. HEIC and AVIF input depend on the browser decoder; use a supported source if loading fails.

Read the related workflow guide for choosing settings and verifying exports.

Which format to pick

WebP often produces smaller files than JPEG and supports transparency, which makes it the default choice for anything going on a modern website. JPG is still the safest bet when you are emailing a photo or uploading to an older portal. PNG only earns its size with logos, screenshots and anything that needs a transparent background.

Converting also drops the EXIF metadata, camera GPS coordinates included. That is a handy side effect when you are about to publish a photo.

Common questions

Can it convert iPhone HEIC files?

Only if your browser can open them (Safari can, Chrome on Windows usually cannot). If the image never appears in the list, the browser did not recognise it.
