Base64

Encode and decode text or small files.

Encode bytes as a text representation or decode that representation. Base64 is useful for data transport and debugging, but it adds size and provides no confidentiality.

How to use this tool

  1. Select encode or decode and enter text or a supported small file.
  2. Run the operation.
  3. Check the output and copy or download it as appropriate.

Worked example

The text “hello” encodes as aGVsbG8=. Encoded byte length is roughly four thirds of the original, rounded to groups of four, before line wrapping or metadata.

Limitations and checks

Base64 is not encryption. Invalid input or a non-text decoded file may not render as readable text. Large files can consume much more memory during encoding.
