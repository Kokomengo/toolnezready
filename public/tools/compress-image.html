Compress photos

Push the file size down to just before it shows.

Reduce the size of photographs by changing output quality and, when appropriate, pixel dimensions. The result is a new JPEG or WebP, so retain the original if you need to edit again.

How to use this tool

  1. Add your photos and choose a maximum width.
  2. Start near the default quality and choose whether to export WebP.
  3. Compress, inspect fine details at full size, then download individually or as a ZIP.

Worked example

For a 4000-pixel-wide photo used in a 1280-pixel blog layout, select 1280 px first. Lower quality only if the image still exceeds your target size.

Limitations and checks

There is no guaranteed reduction or exact target in kilobytes. Text and sharp edges show artifacts sooner than photographs. Compression does not preserve animation or camera metadata.

Read the related workflow guide for choosing settings and verifying exports.

How much quality you can drop

Between 70 and 80 almost nobody can tell the result from the original on a screen, and the file usually ends up around a fifth of the size. Below 60 you start to see blocking in skies and flat areas of colour.

Shrinking the width does more than lowering quality: a 4000 px phone photo that will be shown 800 px wide in a blog post does not need the other 3200.
