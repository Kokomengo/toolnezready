Get the text out of a PDF

Copy and paste without fighting the viewer.

Read the text layer of a PDF into a copyable plain-text result. This avoids fighting a PDF viewer when the document already contains embedded text.

How to use this tool

  1. Select a text-based PDF.
  2. Extract the text and review page transitions.
  3. Copy or save the result and correct reading order where needed.
Drop a PDFWorks when the PDF holds real text, not when it is a scanned photo

Worked example

A PDF created from a word processor often has a readable text layer. A photograph of a printed page stored inside a PDF can produce an empty result because it needs OCR.

Limitations and checks

No optical character recognition is performed. Columns, tables and unusual fonts may extract in the wrong order. The result does not retain the original layout or signatures.

Read the related workflow guide for choosing settings and verifying exports.
