Convert video

Move a clip to WebM or MP4 and set the frame rate.

Re-encode a playable clip into a browser-supported output container. Source decoding and output encoding are separate capabilities: a browser may play MP4 but only export WebM.

How to use this tool

  1. Add the source and select the time range.
  2. Choose WebM or a supported MP4 option, frame rate and bitrate.
  3. Convert, then check the actual extension and play the result in its destination app.

Video is re-encoded by playing it through, so the job takes roughly as long as the selected clip. Keep the tab visible while it runs.

Worked example

A screen recording intended for a website can be exported as WebM at 30 fps. If an upload form explicitly requires MP4, use a browser that supports MP4 recording or a desktop converter.

Limitations and checks

MP4 export is unavailable in some browsers. The tool cannot convert a codec the browser cannot decode. This process changes encoding and may lose quality.
