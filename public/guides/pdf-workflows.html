Photos, PDF pages and text layers: choose the right document workflow

ToolNez editorial · Updated 25 October 2026

A PDF is a container for page content, not a guarantee of selectable text. It can contain embedded text, scanned images, vector drawings or a mixture. The right tool depends on what is inside the document and what the receiving person needs.

Put photos into one PDF

Use Images to PDF for a collection of receipt photos, handwritten notes or scans. Each image becomes one page. Order the files with the up/down controls, then choose A4, Letter or a page fitted to the photo.

For a three-page receipt submission, check that every amount is readable and the images are the right way up before building. A standard page with a modest margin is useful for printing. The tool embeds JPEG images and can downscale large originals, so inspect small text in the resulting PDF rather than assuming source quality was preserved.

This does not merge existing PDFs, make the text searchable or retain digital signatures. Keep original signed documents unchanged if someone needs to verify their authenticity.

Export a page as an image

PDF to images renders a page into a PNG. That is useful when a presentation needs a picture of a page, or a portal accepts images rather than PDFs. Choose only the necessary pages and a rendering scale suited to the destination.

A higher scale makes more pixels and can improve readability at larger display sizes, but it also increases memory and file size. The PNG contains flattened visual content: text is no longer selectable and vector objects are no longer editable.

Extract an existing text layer

Try selecting a sentence in your PDF viewer. If selection works, Get the text out of a PDF may be able to read the embedded layer. Review the extracted text before reusing it. Two-column layouts, tables and unusual fonts can produce the wrong reading order.

If a scanned page produces an empty result, it probably contains only pixels. It needs optical character recognition, or OCR. ToolNez does not perform OCR; repeatedly extracting the same scan will not create a text layer.

Make a simple PDF from plain notes

Text to PDF paginates plain text using a built-in Helvetica font and WinAnsi encoding. It is suitable for basic notes in supported Western European characters. Emoji and non-Latin writing need a document editor with appropriate embedded fonts.

Markdown PDF export also simplifies formatting. Keep the .md source if you need to edit later, and use an office or layout editor for complex tables, images or precise typography.

Understand local processing

The PDF reading tools download pdf.js and its worker from a CDN. That request reveals ordinary connection information to the CDN, but the selected document bytes are processed in the browser. Loading can fail if the library request is blocked. For very sensitive material, consider an offline document application.

Check the final document

Open every exported file. Verify page count, order, orientation, small print and characters. Do not replace the source until the recipient confirms that the exported version meets the requirement.
