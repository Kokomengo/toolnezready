Choose an image format and reduce file size without losing the wrong details

ToolNez editorial · Updated 25 October 2026

A request to make an image “smaller” can mean fewer bytes, fewer pixels or a different shape. Identify the destination requirement before exporting. A form asking for a 600 × 600 picture needs dimensions and possibly a crop; an email limit asks for bytes. Changing the file extension does neither.

Start with what the image contains

JPEG is a practical choice for photographs because it trades some detail for smaller files and broad compatibility. It cannot preserve a transparent background. PNG preserves transparency and sharp raster edges, but a full-resolution photograph can be considerably larger. WebP can combine transparency with efficient compression on modern websites; verify that the destination accepts it.

For a transparent logo, use Convert images with PNG or WebP. For a picture sent to an older upload form, JPEG is often the safer supported option. None of these choices guarantees a particular reduction: the image and original encoding matter.

Reduce dimensions before pushing quality too low

Suppose a 4000 × 3000 photograph will display at 1200 × 900. Keeping all 12 million source pixels wastes data for that use. Resize a copy to the intended dimensions, then examine it at the size people will actually see. The smaller copy is unsuitable as a replacement for an archival original or a large print.

In Compress photos, pick a maximum width and begin near the default quality. Inspect hair, foliage, small text and high-contrast edges. Lower quality in small steps only while the result remains acceptable. Repeatedly compressing previous exports compounds damage; restart from the source for each comparison.

Crop when the shape is wrong

A landscape photo destined for a square avatar should be cropped around its subject rather than stretched. Use Crop image with a 1:1 frame, then resize if required. Leave some space around the subject because the destination may apply a circular or additional crop.

Check properties that can change during export

ToolNez uses the browser canvas to produce a new raster image. Original EXIF metadata and animation are not retained. Removing camera metadata can help avoid publishing location details, but it also removes information you may want to archive. Keep the original separately.

Converting a transparent image to JPEG discards transparency; inspect the resulting background. HEIC input is browser-dependent. If the browser cannot decode a source, selecting a different output format will not fix the input decoder.

Validate the saved copy

  1. Open the exported file, rather than checking only the on-page preview.
  2. Verify dimensions, file size, background and readability.
  3. Test it in the receiving form or application.
  4. Keep the source until the destination accepts the result.

This process gives you a repeatable decision path: correct the shape, set the dimensions, choose a compatible format, then adjust quality. It is more useful than aiming for a universal compression percentage.
