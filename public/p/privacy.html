Privacy

Last updated: 25 October 2026. ToolNez provides static browser tools without user accounts. Selected file bytes and calculation inputs are processed locally; ToolNez does not provide an upload API for these files.

Data in your browser

localStorage keeps your theme, favorite tools, recently opened tools, some settings and the Markdown draft. These remain until you clear the site’s browser data. Generated passwords are not saved by ToolNez. Export important drafts because local storage is not a backup.

Hosting and external requests

Vercel serves the site and may process IP addresses, request paths and ordinary connection logs under its hosting policies. PDF reading tools fetch pdf.js and its worker from cdnjs, which receives connection information. Remote images referenced in a Markdown preview can contact their hosts. These requests do not upload the selected PDF to a ToolNez server.

Advertising

Google advertising code is currently disabled. The publisher verification meta tag does not itself load ads or set advertising cookies. If advertising is enabled later, Google and its partners may use cookies or similar identifiers to measure ads and, where permitted, personalize them based on visits to this and other sites. Required consent must be collected before ad code runs.

You can manage personalization in Google My Ad Center and read how Google uses information from partner sites. Browser settings can also remove or block stored site data.

Contacting us

If you email us, the email provider handles the message and we receive the information you send to answer it. Do not attach sensitive source files. Privacy questions: elmillodel2029@gmail.com.
